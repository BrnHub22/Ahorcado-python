# 🎮 Juego del Ahorcado en Python

Clásico juego del ahorcado por consola. Adivina la palabra secreta letra por letra antes de quedarte sin vidas.

### Temática actual: Cultura Urbana

---

### ✨ Características
- El jugador consta de 3 vidas por partida <3.
- Incluye una pista incluida: "La palabra secreta es parte de una cultura urbana".
- Sistema de validación: No permite números, caracteres especiales ni más de una letra.
- El sistema te arroja las vidas que te quedan.
### 🚀 Cómo jugar

1. Asegúrate de tener Python instalado
2. Descarga el archivo (`Ahoracado.py`) 
3. Abrelo en Python corre el juego y diviertete
