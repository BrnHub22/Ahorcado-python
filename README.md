# 🎮 Juego del Ahorcado en Python

Clásico juego del ahorcado por consola. Adivina la palabra secreta letra por letra antes de quedarte sin intentos.

### Características
- ✅ Banco de palabras desde `palabras.txt`
- ✅ 6 intentos máximo con dibujo ASCII del ahorcado
- ✅ Valida que solo ingreses una letra y que no esté repetida
- ✅ Muestra letras usadas y progreso de la palabra
- ✅ Mensaje de victoria/derrota al final

### Requisitos
Python 3.8 o superior

No necesitas instalar librerías externas. Solo usa módulos nativos de Python.

### Cómo jugar
1. Al iniciar, el juego elige una palabra al azar
2. Verás `_ _ _ _` según la cantidad de letras
3. Ingresa una letra y presiona Enter
4. Si aciertas, se revela en la palabra
5. Si fallas, pierdes 1 vida
6. Ganas si completas la palabra antes del 6to error
